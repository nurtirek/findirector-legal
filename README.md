# Финдиректор: публичные правовые страницы

Отдельный репозиторий информационных страниц Wire group. Исходников приложения, клиентских документов, данных ресторанов и ключей здесь нет.

## Статус

`privacy.html` пока содержит уведомление о подготовке политики и контакты. Это НЕ окончательная политика конфиденциальности и НЕ готовый URL для декларации Google Play. Окончательная версия заменит содержимое по тому же адресу после проверки фактических условий обработки, хранения и удаления данных.

На опубликованных страницах нет форм, аналитики, внешних скриптов или шрифтов. Они размещаются на GitHub Pages; обработка сетевых запросов самим хостингом регулируется условиями GitHub.
